# Privacy Policy

_Last updated: 2026-05-05_

This policy covers the `clarify` Claude Code plugin in this repository.

## What we collect

Nothing. The plugin runs locally inside Claude Code. It has no servers, no analytics, no telemetry, and makes no network calls of its own.

## Third parties

When you use `/clarify:clarify`, your prompts and Claude's responses are processed by Anthropic through Claude Code, governed by [Anthropic's Privacy Policy](https://www.anthropic.com/legal/privacy). This plugin does not add any additional data flows.

## Children's privacy

This plugin is not directed at children under 13.

## Changes

Material changes will update this file and bump the "Last updated" date. Full history is visible via git.

## Contact

For privacy questions, open an issue at https://github.com/otar/clarify-skill/issues.
